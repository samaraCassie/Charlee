## 17. Charlee Focus - Sistema de Gestão de Notificações

### 17.1 Visão Geral

**Charlee Focus** é o módulo responsável por filtrar, curar e gerenciar o tsunami de notificações digitais que competem pela atenção de Samara diariamente. Ele evolui de um simples filtro para um verdadeiro **orquestrador cognitivo** que protege foco, energia mental e bem-estar.

**Problema que resolve:**
- 200+ notificações/dia de múltiplas fontes
- Interrupções constantes prejudicam deep work
- Sobrecarga de decisões ("devo responder isso agora?")
- Ansiedade de perder algo importante
- Burnout de comunicação

**Solução:**
Um agente que **filtra ruído**, **prioriza sinal**, **gera respostas**, **agenda ações** e **protege foco** - tudo isso aprendendo continuamente com seus padrões e preferências.

#### 17.4.1 NotificationAgent (Coletor)

**Responsabilidade:** Conectar com múltiplas fontes e centralizar notificações

```python
from agno.agent import Agent
from agno.models.openai import OpenAIChat
import imaplib
import email
from slack_sdk import WebClient
import requests

class NotificationAgent(Agent):
    """Agente que coleta notificações de múltiplas fontes"""
    
    def __init__(self, db_connection, sources_config):
        self.db = db_connection
        self.sources = sources_config
        
        super().__init__(
            name="Notification Collector",
            model=OpenAIChat(id="gpt-4o-mini"),  # Modelo rápido para coleta
            instructions=[
                "Você coleta notificações de múltiplas fontes",
                "Normaliza formato para estrutura comum",
                "Detecta duplicatas e threads"
            ]
        )
    
    def collect_from_email(self, email_config):
        """Coleta emails não lidos"""
        mail = imaplib.IMAP4_SSL(email_config['host'])
        mail.login(email_config['user'], email_config['password'])
        mail.select('INBOX')
        
        _, messages = mail.search(None, 'UNSEEN')
        notifications = []
        
        for num in messages[0].split():
            _, msg = mail.fetch(num, '(RFC822)')
            email_body = email.message_from_bytes(msg[0][1])
            
            notification = {
                'source': 'email',
                'external_id': num.decode(),
                'remetente': email_body['From'],
                'assunto': email_body['Subject'],
                'corpo': self.extract_email_body(email_body),
                'recebida_em': email_body['Date']
            }
            notifications.append(notification)
        
        return notifications
    
    def collect_from_slack(self, slack_config):
        """Coleta mensagens não lidas do Slack"""
        client = WebClient(token=slack_config['token'])
        
        # Busca menções e DMs
        response = client.conversations_list(types="im,mpim")
        notifications = []
        
        for channel in response['channels']:
            # Pega mensagens não lidas
            history = client.conversations_history(
                channel=channel['id'],
                limit=50
            )
            
            for message in history['messages']:
                if not message.get('is_read', True):
                    notification = {
                        'source': 'slack',
                        'external_id': message['ts'],
                        'remetente': message.get('user'),
                        'corpo': message['text'],
                        'url': f"slack://channel?id={channel['id']}&message={message['ts']}",
                        'recebida_em': message['ts']
                    }
                    notifications.append(notification)
        
        return notifications
    
    def collect_from_linkedin(self, linkedin_config):
        """Coleta notificações do LinkedIn"""
        # API do LinkedIn (requer OAuth)
        headers = {
            'Authorization': f"Bearer {linkedin_config['access_token']}"
        }
        
        response = requests.get(
            'https://api.linkedin.com/v2/notifications',
            headers=headers
        )
        
        notifications = []
        for item in response.json()['elements']:
            notification = {
                'source': 'linkedin',
                'external_id': item['id'],
                'tipo': item['type'],  # 'message', 'connection_request', etc
                'corpo': item['text'],
                'url': item['actionUrl'],
                'recebida_em': item['createdAt']
            }
            notifications.append(notification)
        
        return notifications
    
    def collect_all(self):
        """Coleta de todas as fontes ativas"""
        all_notifications = []
        
        for source in self.sources:
            if not source['ativo']:
                continue
            
            try:
                if source['tipo'] == 'email':
                    notifications = self.collect_from_email(source['config'])
                elif source['tipo'] == 'slack':
                    notifications = self.collect_from_slack(source['config'])
                elif source['tipo'] == 'linkedin':
                    notifications = self.collect_from_linkedin(source['config'])
                # ... outros tipos
                
                all_notifications.extend(notifications)
                
                # Atualiza ultima_sync
                self.update_source_sync(source['id'])
                
            except Exception as e:
                logger.error(f"Erro coletando de {source['tipo']}: {e}")
        
        return all_notifications
    
    def save_notifications(self, notifications):
        """Salva notificações no banco"""
        for notif in notifications:
            # Verifica duplicata
            existing = self.db.execute(
                "SELECT id FROM notifications WHERE external_id = %s AND source = %s",
                (notif['external_id'], notif['source'])
            ).fetchone()
            
            if not existing:
                self.db.execute("""
                    INSERT INTO notifications 
                    (source_id, external_id, remetente, assunto, corpo, url, recebida_em)
                    VALUES (%s, %s, %s, %s, %s, %s, %s)
                """, (...))
```

#### 17.4.2 ClassifierAgent (Classificador Inteligente)

**Responsabilidade:** Analisar semanticamente e classificar notificações

```python
class ClassifierAgent(Agent):
    """Agente que classifica notificações usando LLM"""
    
    def __init__(self, db_connection, vector_db):
        self.db = db_connection
        self.vector_db = vector_db
        
        super().__init__(
            name="Notification Classifier",
            model=OpenAIChat(id="gpt-4o"),
            storage=vector_db,
            instructions=[
                "Você é especialista em classificar notificações",
                "Analise contexto, urgência, intenção e tom",
                "Considere padrões históricos de Samara",
                "Seja conservador com 'urgente' - apenas emergências reais"
            ]
        )
    
    def classify_notification(self, notification):
        """Classifica uma notificação"""
        
        # Busca contexto similar
        similar_context = self.vector_db.search(
            query=notification['corpo'],
            limit=5
        )
        
        # Monta prompt
        prompt = f"""
Classifique esta notificação:

Remetente: {notification['remetente']}
Assunto: {notification.get('assunto', '')}
Corpo: {notification['corpo']}

Contexto histórico similar:
{self.format_context(similar_context)}

Retorne JSON com:
{{
    "categoria": "urgente" | "importante" | "informativo" | "spam",
    "prioridade": 1-5,
    "intencao": "solicitacao" | "informacao" | "convite" | "cobranca" | "spam",
    "tom_emocional": "neutro" | "urgente" | "amigavel" | "formal" | "agressivo",
    "contexto": {{
        "projeto": null ou nome do projeto,
        "tipo": tipo da notificação,
        "stakeholder": pessoa relevante ou null
    }},
    "acao_sugerida": "responder" | "arquivar" | "criar_tarefa" | "agendar_reuniao" | "ignorar",
    "justificativa": "breve explicação da classificação"
}}
"""
        
        response = self.print_response(prompt, stream=False)
        classification = json.loads(response)
        
        # Extrai entidades
        entities = self.extract_entities(notification['corpo'])
        
        # Gera embedding
        embedding = self.generate_embedding(notification['corpo'])
        
        # Atualiza no banco
        self.db.execute("""
            UPDATE notifications
            SET categoria = %s,
                prioridade = %s,
                intencao = %s,
                tom_emocional = %s,
                contexto = %s,
                acao_sugerida = %s,
                entidades_extraidas = %s,
                embedding = %s,
                processada_em = NOW()
            WHERE id = %s
        """, (
            classification['categoria'],
            classification['prioridade'],
            classification['intencao'],
            classification['tom_emocional'],
            json.dumps(classification['contexto']),
            classification['acao_sugerida'],
            json.dumps(entities),
            embedding,
            notification['id']
        ))
        
        return classification
    
    def extract_entities(self, text):
        """Extrai entidades (pessoas, datas, locais) usando NER"""
        prompt = f"""
Extraia entidades deste texto:
{text}

Retorne JSON:
{{
    "pessoas": [...],
    "datas": [...],
    "locais": [...],
    "projetos": [...],
    "empresas": [...]
}}
"""
        response = self.print_response(prompt, stream=False)
        return json.loads(response)
    
    def classify_batch(self, notifications):
        """Classifica múltiplas notificações em lote"""
        for notif in notifications:
            try:
                self.classify_notification(notif)
            except Exception as e:
                logger.error(f"Erro classificando notificação {notif['id']}: {e}")
```

```python
        self.vector_db = vector_db

Contexto relevante:

3. Use dados específicos do contexto quando relevante
4. Seja concisa (máximo 3 parágrafos)
5. Inclua próximos passos claros se aplicável
"""
        
        response = self.print_response(prompt, stream=False)
        
        # Salva rascunho
        self.db.execute("""
            UPDATE notifications
            SET rascunho_resposta = %s
            WHERE id = %s
        """, (response, notification_id))

                FROM tarefas t
                JOIN big_rocks br ON t.big_rock_id = br.id
                WHERE br.nome = %s
            """, (projeto,)).fetchone()

                'nome': projeto,
                'total_tasks': tasks['total'],
                'concluidas': tasks['concluidas'],
                'progresso': (tasks['concluidas'] / tasks['total'] * 100) if tasks['total'] > 0 else 0
            }
        
        # Se menciona uma pessoa
        if notification['entidades_extraidas'] and notification['entidades_extraidas'].get('pessoas'):
            # Busca histórico de comunicação
            pass
        
        return context
```

#### 17.4.4 FocusGuardAgent (Protetor de Foco)

**Responsabilidade:** Gerenciar blocos de foco e interrupções

```python
class FocusGuardAgent(Agent):
    """Agente que protege períodos de deep work"""
    
    def __init__(self, db_connection):
        self.db = db_connection
        
        super().__init__(
            name="Focus Guardian",
            model=OpenAIChat(id="gpt-4o-mini"),
            instructions=[
                "Você protege o foco e a concentração de Samara",
                "Bloqueie interrupções durante deep work",
                "Apenas notificações CRÍTICAS passam",
                "Gere resumos para períodos de foco"
            ]
        )
    
    def start_focus_session(self, tipo='deep_work', duracao_minutos=120):
        """Inicia uma sessão de foco"""
        session = {
            'inicio': datetime.now(),
            'fim': datetime.now() + timedelta(minutes=duracao_minutos),
            'tipo': tipo,
            'ativo': True
        }
        
        session_id = self.db.execute("""
            INSERT INTO focus_sessions (inicio, fim, tipo)
            VALUES (%s, %s, %s)
            RETURNING id
        """, (session['inicio'], session['fim'], session['tipo'])).fetchone()['id']
        
        # Ativa modo não perturbe
        self.enable_do_not_disturb()
        
        logger.info(f"🎯 Sessão de foco iniciada: {tipo} por {duracao_minutos} min")
        
        return session_id
    
    def process_notification_during_focus(self, notification):
        """Decide se notificação interrompe sessão de foco"""
        
        # Verifica se há sessão ativa
        active_session = self.db.execute("""
            SELECT * FROM focus_sessions
            WHERE inicio <= NOW() AND fim >= NOW()
            ORDER BY inicio DESC
            LIMIT 1
        """).fetchone()
        
        if not active_session:
            return 'allow'  # Sem sessão ativa, permite
        
        # Classifica urgência REAL
        if notification['categoria'] == 'urgente':
            # Verifica se é urgência verdadeira
            is_truly_urgent = self.verify_urgency(notification)
            
            if is_truly_urgent:
                logger.warn(f"⚠️ Interrupção permitida: {notification['assunto']}")
                return 'allow'
            else:
                logger.info(f"🛡️ Bloqueada falsa urgência: {notification['assunto']}")
                return 'snooze'
        else:
            # Não é urgente, adia para fim da sessão
            snooze_until = active_session['fim']
            self.db.execute("""
                UPDATE notifications
                SET snooze_until = %s
                WHERE id = %s
            """, (snooze_until, notification['id']))
            
            # Incrementa contador
            self.db.execute("""
                UPDATE focus_sessions
                SET interrupcoes_bloqueadas = interrupcoes_bloqueadas + 1,
                    notificacoes_adiadas = array_append(notificacoes_adiadas, %s)
                WHERE id = %s
            """, (notification['id'], active_session['id']))
            
            return 'blocked'
    
    def verify_urgency(self, notification):
        """Verifica se urgência é legítima"""
        urgent_patterns = [
            'servidor down',
            'produção quebrada',
            'deploy falhou',
            'emergência',
            'urgentíssimo',
            'imediato'
        ]
        
        texto = (notification.get('assunto', '') + ' ' + notification['corpo']).lower()
        
        for pattern in urgent_patterns:
            if pattern in texto:
                return True
        
        # Checa remetente (stakeholders críticos)
        critical_senders = ['senior@syssa.com', 'ceo@', 'investidor@']
        for sender in critical_senders:
            if sender in notification['remetente'].lower():
                return True
        
        return False
    
    def end_focus_session(self, session_id, qualidade_foco=None):
        """Finaliza sessão e gera resumo"""
        self.db.execute("""
            UPDATE focus_sessions
            SET fim = NOW(),
                qualidade_foco = %s
            WHERE id = %s
        """, (qualidade_foco, session_id))
        
        # Busca notificações adiadas
        snoozed = self.db.execute("""
            SELECT * FROM notifications
            WHERE id = ANY(
                SELECT unnest(notificacoes_adiadas)
                FROM focus_sessions
                WHERE id = %s
            )
        """, (session_id,)).fetchall()
        
        # Gera resumo
        summary = self.generate_focus_summary(session_id, snoozed)
        
        # Libera notificações adiadas
        for notif in snoozed:
            self.db.execute("""
                UPDATE notifications
                SET snooze_until = NULL
                WHERE id = %s
            """, (notif['id'],))
        
        logger.info(f"✅ Sessão de foco finalizada. {len(snoozed)} notificações adiadas.")
        
        return summary
    
    def generate_focus_summary(self, session_id, snoozed_notifications):
        """Gera resumo do período de foco"""
        session = self.db.execute(
            "SELECT * FROM focus_sessions WHERE id = %s",
            (session_id,)
        ).fetchone()
        
        duracao = (session['fim'] - session['inicio']).total_seconds() / 60
        
        summary = f"""
🎯 RESUMO DA SESSÃO DE FOCO

Tipo: {session['tipo']}
Duração: {duracao:.0f} minutos
Qualidade: {session['qualidade_foco'] or 'Não avaliada'}/10

🛡️ Proteção:
• Interrupções bloqueadas: {session['interrupcoes_bloqueadas']}
• Notificações adiadas: {len(snoozed_notifications)}

📬 Durante sua sessão de foco, você recebeu:
"""
        
        if snoozed_notifications:
            for notif in snoozed_notifications[:5]:  # Top 5
                summary += f"• {notif['remetente']}: {notif.get('assunto', notif['corpo'][:50])}\n"
            
            if len(snoozed_notifications) > 5:
                summary += f"... e mais {len(snoozed_notifications) - 5}\n"
        else:
            summary += "• Nenhuma notificação importante\n"
        
        summary += "\n💡 Todas as notificações já estão disponíveis para revisão."
        
        return summary
```

### 17.10 Política de Retenção e Limpeza de Dados

**Problema**: Sem política de retenção, sistema acumula ~711k notificações em 5 anos (5.5GB), degradando performance e aumentando custos.

**Solução**: Limpeza automática em camadas que mantém dados importantes e remove desnecessários.

#### Política de Retenção por Categoria

| Categoria | Retenção Ativa | Retenção Arquivada | Retenção Total |
|-----------|----------------|-------------------|----------------|
| **🔴 Urgente** | 90 dias | 1 ano | 1 ano |
| **🟡 Importante** | 180 dias | 2 anos | 2 anos |
| **🔵 Informativo** | 30 dias | 6 meses | 6 meses |
| **⚫ Spam** | 7 dias | 30 dias | 30 dias |

#### Ciclo de Vida de Notificações

```
1. RECEBIMENTO → Classificada por IA
2. ESTADO ATIVO → Visível em inbox
3. ARQUIVAMENTO AUTO → Após período de retenção ativa
4. COLD STORAGE → Comprimida, embedding removido (>6 meses)
5. DELETAÇÃO → Permanente após período de retenção total
```

#### Estratégias de Limpeza Automática

**Limpeza Diária (03:00)**
- Arquivar spam imediatamente após classificação
- Arquivar informativos lidos após 7 dias
- Arquivar notifs lidas com >30 dias

**Limpeza Semanal (Domingos 02:00)**
- Deletar spam arquivado há >30 dias (~2000 notifs/semana)
- Deletar informativos arquivados há >6 meses (~500 notifs/semana)
- Comprimir notifs antigas (remover embeddings >90 dias)

**Limpeza Mensal (Dia 1, 01:00)**
- Deletar urgentes arquivadas há >1 ano
- Deletar importantes arquivadas há >2 anos
- VACUUM database para reclamar espaço

**Limpeza Semestral (Jan/Jul)**
- Mover notifs >180 dias para cold storage (S3 Glacier)
- Agregar estatísticas antigas
- Reindexar embeddings (HNSW)

**Limpeza Anual (Janeiro)**
- Auditoria completa de dados (compliance LGPD)
- Relatório anual ao usuário
- Deletar tudo além da política de retenção

#### Impacto da Política

**Sem Política (5 anos):**

- Queries: 10-30 segundos
- Busca similaridade: 60+ segundos

**Com Política (5 anos):**

```python
import re

sensitive_patterns = {
    'cpf': r'\d{3}\.\d{3}\.\d{3}-\d{2}',
    'cartao_credito': r'\d{4}[\s-]?\d{4}[\s-]?\d{4}[\s-]?\d{4}',

        text = re.sub(pattern, f'[{pattern_name.upper()}_REDACTED]', text, flags=re.IGNORECASE)
    return text

# Uso
```

### 17.15 Webhooks e Real-Time

#### Substituir Polling por Webhooks

**Problema**: Polling a cada 15 minutos desperdiça quota de API.

**Solução**: Webhooks para notificação em tempo real.

```python
# Endpoint para receber webhooks
@app.post("/api/v2/webhooks/{source_type}")
async def receive_webhook(
    source_type: str,
    request: Request,
    signature: str = Header(None)
):
    # 1. Validar assinatura
    body = await request.body()
    if not verify_signature(source_type, body, signature):
        raise HTTPException(401, "Assinatura inválida")

    # 2. Parsear payload
    payload = await request.json()

    # 3. Processar assincronamente
    task = process_webhook_notification.delay(source_type, payload)

    return {"status": "accepted", "task_id": task.id}

def verify_signature(source_type: str, body: bytes, signature: str) -> bool:
    """Verifica assinatura do webhook."""
    if source_type == 'slack':
        # Slack usa HMAC-SHA256
        import hmac
        secret = get_slack_signing_secret()
        computed = hmac.new(secret, body, hashlib.sha256).hexdigest()
        return hmac.compare_digest(computed, signature)

    elif source_type == 'github':
        # GitHub usa X-Hub-Signature-256
        secret = get_github_webhook_secret()
        computed = hmac.new(secret, body, hashlib.sha256).hexdigest()
        return signature == f"sha256={computed}"

    return False
```

**Configuração de Webhooks:**

| Fonte | Webhook URL | Eventos |
|-------|-------------|---------|
| Slack | `https://charlee.app/api/v2/webhooks/slack` | `message.channels`, `message.im` |
| GitHub | `https://charlee.app/api/v2/webhooks/github` | `notifications`, `pull_request` |
| Discord | `https://charlee.app/api/v2/webhooks/discord` | `MESSAGE_CREATE` |

**Benefícios:**
- ⚡ Notificações em <1 segundo (vs 15 minutos)
- 💰 Reduz 95% das chamadas de API (sem polling)
- 🔋 Menos carga no servidor
