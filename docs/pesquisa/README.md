## Ideia central dos três estudos

1. **O ciclo afeta sintomas, não a capacidade intelectual** — e os sintomas são individuais.
2. **Aprender o padrão de cada pessoa** a partir dos próprios registros é melhor que aplicar tabelas genéricas por fase.
3. **Planejar com faixas de incerteza** (nunca datas exatas) e **proteger os dias de risco com folga e flexibilidade**.
