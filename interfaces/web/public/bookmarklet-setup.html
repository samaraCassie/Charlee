Bookmarklet Setup

Importe oportunidades com 1 clique

1 Arraste para a barra de favoritos

Charlee Import

Arraste o botao acima para sua barra de favoritos
(Nao clique - arraste!)

Dica: Se sua barra de favoritos nao estiver visivel, pressione Ctrl+Shift+B (Windows/Linux) ou Cmd+Shift+B (Mac).

2 Como usar

  1. Navegue ate uma pagina de projeto em uma plataforma suportada
  2. Clique no bookmark "Charlee Import"
  3. A oportunidade sera criada automaticamente no Charlee
  4. Uma notificacao confirmara a importacao
Importante: Voce precisa estar logado no Charlee para que a importacao funcione automaticamente. Se nao estiver logado, o Charlee abrira em uma nova aba com os dados pre-preenchidos.

Outras plataformas: O bookmarklet tentara extrair dados basicos (titulo e descricao) de qualquer pagina, mas funciona melhor nas plataformas listadas.

4 O que e extraido

  • Titulo do projeto
  • Descricao completa
  • Orcamento (quando disponivel)
  • Skills requeridas
  • Informacoes do cliente (nome, rating, pais)
  • URL original para referencia

Problemas?

Se o bookmarklet nao estiver funcionando:

  1. Verifique se voce esta logado no Charlee
  2. Certifique-se de que esta na pagina de um projeto especifico (nao na listagem)
  3. Alguns ad-blockers podem interferir - tente desativar temporariamente
  4. Se nada funcionar, use o Smart Paste para colar o texto do projeto manualmente
